- `reproduction/` package (24K LoC) → moved to `quantnodes.research`

### Migration
- `from llmwikify.reproduction.X` → `from quantnodes.research.X` (quantnodes>=4.0)
- HTTP `/api/{factor,paper,reproduction,strategy}/*` → moved to quantnodes
