## 1. 本次相对上次的变更

### 性能（核心）

| 项 | 0.40.2（线上） | 0.40.3（本次） |
|---|---|---|
| `/api/wiki/graph` 构图 | O(E²) 去重，16869 链接约 3–25s | **O(E) 字典去重**，同数据 **0.02–0.2s** |
| `graph_analyze` | 每次全量 PageRank/社区，约 1.5s+（缺 networkx 时先构图再空返回） | 指纹缓存；冷 ~2s，热 **~0.008s**；启动预热后首击 ~0.05s |
| suggestions 页存在性 | 逐节点 `rglob` 全库（大库数十秒） | 一次 page-name set |
| 图接口线程模型 | `async def` 内跑 CPU 重活 → 卡事件循环 | 同步 `def` 进线程池 |
| viz 缓存 | 无 | 与 analyze 共用指纹，TTL 60s |

### 正确性 / 兼容

| 修复 | 说明 |
|---|---|
| MCP 挂载 | FastMCP `http_app()` 默认内部 `/mcp`，挂到 `/mcp` 变成 `/mcp/mcp` 404 → 改为 `http_app(path="/")` |
| SPA 兜底 | WebUI 404 兜底曾把 `/mcp` 打成 index.html → 排除 `/mcp` |
| UTF-8 | prompt 模板 / storage 读写强制 UTF-8（Windows 本地开发） |
| 关系边去重 | `(src,tgt,relation)` 真去重，避免 PageRank 重复计权 |

### 依赖 / 镜像

| 项 | 0.40.2-slim | 0.40.3-slim |
|---|---|---|
| extras | 含 extractors（pymupdf/onnx/pandas…） | 默认 **不含 extractors**（服务端只读 wiki） |
| 体积 | ~680MB+（线上 slim）/ 全量 1.21GB | **610MB** |
| WebUI | 有 | 有（多阶段构建） |

> 若服务器需要收 PDF/Office：`--build-arg LLMWIKIFY_EXTRAS=all` 重建。

### 未变更（与上次相同）

- MCP 会话协议：initialize → notifications/initialized → tools/call → DELETE
- 鉴权：`Authorization: Bearer <PAT>`
- **写工具仍未纳入巡检**（保护生产库）
- `wiki_lint` / `wiki_knowledge_gaps` 全库扫描仍为重操作（秒级～分钟级，与数据规模成正比）

## 3. 使用案例

### 3.1 MCP 客户端（Claude / 自定义）

连接地址：`https://<host>:8443/mcp/mcp`（经 nginx）或 `http://127.0.0.1:8765/mcp/`

```http
POST /mcp/ HTTP/1.1
Authorization: Bearer <PAT>
Content-Type: application/json
Accept: application/json, text/event-stream

{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"my","version":"0"}}}
```

响应头带 `mcp-session-id`，后续请求附带 `Mcp-Session-Id`。

### 3.2 常用工具调用（tools/call）

```json
{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"wiki_search","arguments":{"query":"尿素","limit":5}}}
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"wiki_read_page","arguments":{"page_name":"metrics/尿素企业库存"}}}
{"jsonrpc":"2.0","id":4,"method":"tools/call","params":{"name":"wiki_graph","arguments":{}}}
{"jsonrpc":"2.0","id":5,"method":"tools/call","params":{"name":"wiki_graph_analyze","arguments":{}}}
```

### 3.3 REST（图谱 / 状态）

```bash
curl -H "Authorization: Bearer $PAT" https://host:8443/api/wiki/status
curl -H "Authorization: Bearer $PAT" https://host:8443/api/wiki/graph
curl -H "Authorization: Bearer $PAT" "https://host:8443/api/wiki/graph_analyze"
curl -H "Authorization: Bearer $PAT" "https://host:8443/api/wiki/graph_analyze?force=1"  # 强制重算
```

### 3.4 部署

```bash
# 上传新包（136MB）
rsync -avP llmwikify-server-0.40.3-slim.tar.xz linlu@8.133.234.138:/tmp/
ssh linlu@8.133.234.138
xz -dc /tmp/llmwikify-server-0.40.3-slim.tar.xz | docker load
# compose 中 image: llmwikify-server:0.40.3-slim
cd ~/CKbase/deploy && docker compose up -d
```

### 3.5 本地复测

```bash
# 需 Docker（WSL）
bash scripts/mcp_tool_matrix_retest.sh
bash scripts/rebuild_and_accept.sh   # WebUI + REST + MCP 全链路
```
