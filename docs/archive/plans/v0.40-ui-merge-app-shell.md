# v0.40 UI 合并: Wiki + Agent layout → AppShell

> **Status**: approved 2026-07-07 · **Branch**: `dev/refocus-v0.40-2026-07-05`
> **Scope**: 2 commits · **风险**: 中（视觉变化） · **预期**: 净 -150 行

## 动机

v0.40 前有两个并行 layout:
- `WikiLayout` (251 行): nav = `[Editor, Dashboard, Insights]`, top bar + Notifications, footer = Health + Theme
- `AgentLayout` (216 行): nav = `[Chat, Research, Tasks, Settings]`, 无 top bar, footer = Activity + User

问题:
1. **gold-plating**: 两个 layout 共享 80% 代码（sidebar / brand / footer / state）
2. **Activity 不跨 workspace 可见**: 在 `/edit` 时看不到 pending proposals
3. **视觉不一致**: top bar / footer / Activity badges 位置两边各一套

## 决策矩阵

| 维度 | 决策 |
|---|---|
| URL | 保持 `/agent/*` 兼容 (bookmark/embed 不破) |
| Nav 分组 | **Wiki / Agent 两段** |
| Top + Footer | 完全合并 |
| Backdrop | 仅 `/agent/*` 路径 (useLocation 条件渲染) |
| Activity badges | top bar 右侧 |
| Activity 可见性 | 所有路径 (跨 workspace) |
| Brand icon | **BookOpen** (更稳重) |
| Subtitle | "Workspace" (去 wiki/agent 区分) |
| Commit | 拆 2 commit |

## Commit 1: 新建 AppShell

**文件**:
- 新建 `ui/webui/src/components/shared/AppShell.tsx`
- 移动 `ui/webui/src/components/agent/Backdrop.tsx` → `ui/webui/src/components/shared/Backdrop.tsx`

**AppShell 内部结构**:
- `useLocation()` → `const isAgent = location.pathname.startsWith('/agent')`
- Sidebar: `BookOpen` icon + "Workspace" subtitle + WikiSelector + 2 段 nav + Health + Theme + User
- Top bar: wiki name + Activity badges (Confirmations / Proposals / Notifications) + Notifications bell
- Backdrop 渲染条件: `{isAgent && <Backdrop />}`
- Footer: HealthStatus + Theme toggle + User card (从两边 layout 合并)

**Commit 1 仍引用旧 layout** — App.tsx 暂时不变, 只新增 AppShell. `npm run build` 仍应通过.

## Commit 2: 删除旧 layout + App.tsx 切换
