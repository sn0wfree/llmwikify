## TL;DR

llmwikify v0.40 strips the quant research-and-backtest feature (paper → factor → backtest → report) and refocuses on three core areas: **Knowledge (Wiki)**, **Chat**, and **Research Assistant**. All quant logic has been moved to a separate project, **quantnodes** (at `/home/ll/Public/QuantNodes`).

This document is a **snapshot** of the current state. The release has **NOT been tagged yet**. The 5 server-dependent scenario tests are auto-skipped when no llmwikify server is running; everything else is green.
